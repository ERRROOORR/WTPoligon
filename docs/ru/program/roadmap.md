# План после 2.0-beta

В 2.0-beta есть русское окно с семью шагами, каталог из установленной игры, создание миссии, редакторы подвески,
характеристик и боеприпасов, вызываемая техника, «Моя техника», настройка сценария, проверка до записи, журнал
программы и откат по манифесту. Ниже — планы и темы исследования, без сроков.

| Направление | Что сделать |
|---|---|
| Удобство | Английская локализация интерфейса; обучение при первом запуске и FAQ. |
| Техника | Техника Dev-сервера в обычном клиенте; каждый рабочий способ — с проверкой в игре. |
| Выпуск | Отдельный `.exe`; сейчас бета — ZIP со встроенным Python и `run.bat`. |
| Оружие | Характеристики ракет (дальность, скорость, ГСН, перегрузка, БЧ); пушки наземки на самолёте; ЗУР с РЛ-ГСН и морские ЗУР на пилонах. |
| Датчики | Каналы наведения РЛС; модули РЭБ. |
| Правка техники | Прицел; башня и орудие. |
| Сценарии | Дуэль до 200 км, прорыв ПВО, миссия для ЗРК, морские цели. |
| Боезапас | Таймер штатного пополнения боезапаса; мгновенная перезарядка по кнопке огня. |
| Записи | История применений и отмена выбранного прошлого применения. Сейчас окно показывает записи и откатывает текущую, выбранные или все. |

Для каждой возможности нужны источник в данных игры, корректные создаваемые файлы и проверка в игре. До проверки —
пометка **«не проверено»** или **📄**. См. [чек-лист тестера](../../TESTING.md).
