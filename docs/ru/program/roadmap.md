# План развития

Программа в разработке; это направления работы, а не обещание даты выпуска.

| Направление | Текущее состояние | Следующее действие |
|---|---|---|
| Каталог из установленной игры и создание миссий | Реализовано в разрабатываемой версии | Улучшить совместимость после обновлений игры |
| Конструктор авиационной подвески | Реализован; основной сценарий проверен в игре | Проверить зеркалирование, старые пресеты, вертолёты и другие семейства оружия |
| Общий редактор характеристик | В разработке | Редактировать проверенные поля и показывать остальные BLK-поля со статусом |
| Боеприпасы и сенсоры | Способы исследованы в игре | Добавить удобный интерфейс и проверки для каждого семейства |
| Проекты и обмен | В планах | Сохранение проектов, общая библиотека, импорт и экспорт |
| Справка и выпуск | В планах | Обучение, собранная версия и отдельная лицензия кода |

Для каждого нового поля или заявления о совместимости нужны источник в установленной игре, проверка корректного BLK и опыт в игре. Правка дронов и вызываемой техники, ядерной мощности и непроверенных семейств ракет остаётся темой исследования.
