# План после Beta-1.0

В Beta-1.0 уже есть русское окно с шестью шагами, каталог из установленной игры, генерация миссии, редакторы подвески, характеристик и боеприпасов, настройка сценария, проверка до записи, логи и откат по манифесту. Ниже — планы и темы исследования без обещания сроков.

| Направление | Что сделать |
|---|---|
| Удобство | Английская локализация интерфейса и обучение при первом запуске. |
| Техника | Исследовать технику Dev-сервера в обычном клиенте; каждый рабочий способ проверить в игре. |
| Выпуск | Собрать и проверить отдельный `.exe`; нынешняя бета — ZIP со встроенным Python и `run.bat`. |
| Оружие | Исследовать ядерный снаряд и пушки наземной техники на самолёте. До заявления о поддержке проверить выстрел, эффект и устойчивость игры. |
| Юниты | Исследовать дроны и вызываемую технику в пользовательских миссиях. |
| Записи | Добавить историю применений и отмену выбранного прошлого применения. Сейчас окно показывает записи и откатывает текущую, выбранные или все, но полной истории отмены нет. |

Для каждой возможности нужны источник в данных игры, корректные создаваемые файлы и проверка в игре. До неё ставим **«не проверено»** или **📄**. См. [чек-лист тестера](../../TESTING.md).
