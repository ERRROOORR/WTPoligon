# WT Poligon Beta-1.0

WT Poligon — конструктор одиночных тестовых миссий War Thunder для Windows. Он читает технику, оружие, названия и изображения из установленной игры, а затем записывает пользовательскую миссию и, если нужны правки, небольшие локальные копии BLK. Архивы самой игры не меняются. Интерфейс Beta-1.0 пока на русском.

В окне шесть шагов: **Техника → Подвеска → Характеристики → Боеприпасы → Сценарий → Проверка и запись**. Подвеска нужна самолётам и вертолётам. Можно оставить штатное вооружение, изменить пилоны, характеристики и боекомплект, настроить цели и условия, затем посмотреть список файлов и ошибки до записи. Список уже сделанных записей позволяет их откатить. Подробности — в [руководстве пользователя](user-guide.md), а пункты для проверки — в [чек-листе](../../TESTING.md).

Машина из ангара может выехать под настоящим именем. Машина не из ангара запускается как локальная копия; часть оборудования от модификаций и элементов интерфейса у неё может отсутствовать. Своя авиационная подвеска тоже требует копии. Миссия находится в игре: **Одиночные миссии → Пользовательские → «WTP5 — <машина>»**. Для новой миссии перезапуск не нужен; после смены названия в CSV он может понадобиться. См. [пользовательские миссии](../datamine/user-missions.md) и [модификации](../datamine/modifications.md).

Перед записью программа сверяет созданные копии с установленным источником. Такая проверка подтверждает структуру файлов и значения, но не работу каждой комбинации в бою. **«Проверено в игре»** означает наличие игрового опыта; **«не проверено»** и **📄** отмечают то, что ещё надо испытать. Откат использует манифест и хеши и оставляет файл, изменённый после записи. Устройство кода — в [руководстве разработчика](developer-guide.md).
