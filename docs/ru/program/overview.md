# Как устроена программа

WT Poligon — настольная программа для Windows в разработке. Текущий поток начинается с поиска и выбора техники, затем для авиации идёт шаг подвески, настройка миссии и проверка перед записью. Каталог техники и оружия строится из установленной игры. Окно и конструктор подвески проверялись в игре; общий редактор характеристик ещё создаётся.

| Компонент или путь | Назначение | Единицы | Статус |
|---|---|---|---|
| Установленные `*.vromfs.bin` и BLK | Источник каталога техники, оружия и пресетов | — | Unverified (in files only) |
| `UserMissions/*.blk` | Созданная миссия | — | Verified in game |
| `content/pkg_local/gameData/.../*.blk` | Копии машин, ЛМ, пресетов, сенсоров и оружия | — | Verified in game |
| Локальный манифест и резервные копии | Учёт записи и откат | — | Unverified (in files only) |
| `include` + `@override` | Применение выбранных правок к копиям | единицы исходника | Verified in game |

Планируемый путь записи сначала собирает файлы в памяти, применяет каждую правку к текущему стоковому дереву установленной игры, сверяет тип и итоговое значение, затем записывает только управляемые файлы миссии и локального контента. Манифест хранит пути и хеши для отката; чужие файлы нельзя перезаписывать автоматически. Каркас, каталог, окно, конструктор подвески и учёт файлов уже есть в приватной разработке. Некоторые сценарии окна, зеркалирование подвески, старые пресеты, библиотека и откат ещё требуют прямой проверки пользователем. Выпущенного исполняемого файла нет.
