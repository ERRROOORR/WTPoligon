# Контейнеры VROMFS

Архивы игры, например `aces.vromfs.bin`, `char.vromfs.bin` и `mis.vromfs.bin`, содержат виртуальные файловые системы. Читайте их из установленной игры: этот репозиторий не распространяет архивы и извлечённые файлы. Пути внутри обычно записаны строчными буквами. Служебная запись `?nm` содержит общую таблицу имён BLK; в некоторых архивах есть словарь zstd.

Распаковщик читает заголовок `VRFs`/`VRFx`, определяет способ упаковки, при необходимости снимает обфускацию, распаковывает zstd, проверяет MD5 и обходит таблицы имён и данных. Для бинарного BLK могут понадобиться `?nm` и словарь архива. Перед использованием проверяйте смещения, размеры, хеш и размер распакованных данных. В исследованной версии архивы имели `VRFx` и режим `0x30`; другие режимы требуют отдельной проверки.

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| `*.vromfs.bin` / `VRFx` | Архив и расширенный заголовок с версией игры | байты/версия | Unverified (in files only) |
| Заголовок `size`, `packed_size`, `pack_type` | Размеры до/после упаковки и её режим | байты/код | Unverified (in files only) |
| Архив `?nm`, `*.dict` | Общие имена BLK и необязательный словарь zstd | — | Unverified (in files only) |
| Виртуальный `gamedata/.../*.blk` | Описания объектов игры внутри архива | — | Unverified (in files only) |

Чтение контейнера сверено с независимой распаковкой исследованной версии игры. Это подтверждает разбор, но не будущие варианты архивов.
