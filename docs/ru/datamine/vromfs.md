# Контейнеры VROMFS

Архивы игры, например `aces.vromfs.bin`, `char.vromfs.bin` и `mis.vromfs.bin`, содержат виртуальные файловые системы. Читайте их из установленной игры: этот репозиторий не распространяет архивы и извлечённые файлы. Пути внутри обычно записаны строчными буквами. Служебная запись `?nm` содержит общую таблицу имён BLK; в некоторых архивах есть словарь zstd.

Распаковщик читает заголовок `VRFs`/`VRFx`, определяет способ упаковки, при необходимости снимает обфускацию, распаковывает zstd, проверяет MD5 и обходит таблицы имён и данных. Для бинарного BLK могут понадобиться `?nm` и словарь архива. Перед использованием проверяйте смещения, размеры, хеш и размер распакованных данных. В исследованной версии архивы имели `VRFx` и режим `0x30`; другие режимы требуют отдельной проверки.

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| `*.vromfs.bin` / `VRFx` | Архив и расширенный заголовок с версией игры | байты/версия | Unverified (in files only) |
| Заголовок `size`, `packed_size`, `pack_type` | Размеры до/после упаковки и её режим | байты/код | Unverified (in files only) |
| Архив `?nm`, `*.dict` | Общие имена BLK и необязательный словарь zstd | — | Unverified (in files only) |
| Виртуальный `gamedata/.../*.blk` | Описания объектов игры внутри архива | — | Unverified (in files only) |

Чтение контейнера сверено с независимой распаковкой исследованной версии игры. Это подтверждает разбор, но не будущие варианты архивов.
# Устройство заголовка и данных

| Поле или запись | Где находится | Смысл / тип | Статус | Наблюдение |
|---|---|---|---|---|
| `VRFs` / `VRFx` | Байты 0–3 | Обычная / расширенная сигнатура | Unverified (in files only) | Все изученные архивы имели `VRFx`; читатель должен различать оба варианта. |
| `platform` | Байты 4–7 заголовка | Четырёхбайтовая метка платформы | Unverified (in files only) | Считывается до распаковки; игровое действие не приписывается. |
| `size` | Байты 8–11 | Размер распакованного образа, `u32` little endian | Unverified (in files only) | Ограничивает размер результата распаковки. |
| `packed_size`, `pack_type` | Байты 12–15 | Младшие 26 бит — размер; старшие 6 — код упаковки | Unverified (in files only) | В изученных архивах был `0x30`. |
| Размер расширения, флаги, версия | Расширение `VRFx` | Два `u16` и версия `u32` | Unverified (in files only) | Версия обозначает сборку игры; размер расширения сдвигает начало данных. |
| `0x10`, `0x20`, `0x30` | Код упаковки | Обфусцированный zstd без проверки, без сжатия, обфусцированный zstd с MD5 | Unverified (in files only) | Полная независимая сверка здесь установлена только для `0x30`. |
| Первые и последние 16 байт | Упакованные данные | XOR перед zstd | Unverified (in files only) | Для изученного режима обфускацию снимают до распаковки. |
| 16 байт после упакованных данных | Контейнер `0x30` | MD5 распакованного образа | Unverified (in files only) | Хеши изученных образов сошлись. |
| Смещения и счётчики таблиц имён и данных | Распакованный образ | Смещения и количество, little endian | Unverified (in files only) | Счётчики должны совпадать; имя ведёт к строке с NUL, запись данных — к смещению и размеру. |
| `\xff?nm` | Служебная запись | Общая карта имён BLK, первый байт вне UTF-8 | Unverified (in files only) | Нужна для имён SLIM BLK. |
| `<hash>.dict` | Служебная запись, если есть | Словарь zstd | Unverified (in files only) | Найден в изученных архивах `aces` и `mis`; нужен части BLK. |

Для изображений и ресурсов UI нужны другие декодеры. Часть изображений `units/*.ddsx` использует Oodle, другие данные DDSx могут использовать zstd, LZMA или zlib; это внутренние форматы изображений, а не режимы упаковки VROMFS. Нельзя определять кодек только по пути. Для изученной сборки независимый распаковщик дал 35 568 совпадающих сырых записей из восьми архивов.
