# Справочник по датамайну

Справочник описывает результаты для изученной версии игры и помечает утверждения по уровню доказательства: **Verified in game**, **Unverified (in files only)**, **No effect** или **Crashes game**. Наличие пути в файле подтверждает структуру, но не влияние на игру. «No effect» относится к указанному опыту. В репозитории только описания и придуманные минимальные примеры, без извлечённого содержимого игры.
