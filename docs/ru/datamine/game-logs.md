# Чтение игровых логов `.clog`

Клиент пишет `.clog` в `%LOCALAPPDATA%/WarThunder/.game_logs/`. Это обфусцированный текст. В исследованном формате весь файл проходит XOR с повторяющимся ключом длиной 768 байт. Для достаточно большого лога ключ можно оценить по самому частому байту открытого текста в каждой позиции, предполагая пробел; результат расшифровки надо проверять, поскольку формат может измениться. Не публикуйте сырые логи: в них могут быть локальные пути и сведения об учётной записи или машине.

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| `.game_logs/*.clog` | Файлы логов клиента | байты | Unverified (in files only) |
| XOR-смещение `position % 768` | Позиция повторяющегося ключа в исследованных логах | индекс байта | Unverified (in files only) |
| `including binary file` | `include` разрешён; само по себе это не доказывает влияние правки на игру | — | Unverified (in files only) |
| `cannot find ... for override`, `different types` | Парсер BLK отклонил правку | — | Unverified (in files only) |

Расшифровывайте в личную локальную папку, выбирайте только строки загрузки миссии или ошибок BLK и сопоставляйте их с наблюдением в игре. Чистый лог подтверждает разбор файла, но не игровой эффект.

## Как трактовать свидетельства

| Строка лога или условие | Где находится | Смысл / тип | Статус | Наблюдение |
|---|---|---|---|---|
| `BUILD TIMESTAMP`, версия игры | Начало расшифрованного `.clog` | Данные сборки | Unverified (in files only) | Помогают привязать наблюдение к версии клиента. |
| `including binary file` | Сообщения парсера BLK | Стоковый `include` разрешён | Unverified (in files only) | Повторялась при дальнейших загрузках миссии; не доказывает игровой эффект поля. |
| `cannot find param/block ... for override` | Сообщения парсера BLK | Нет цели с указанным номером | No effect | Проверенная правка пропущена; нужно сверить файл-владелец и номер повтора. |
| `different types ... for override` | Сообщения парсера BLK | Несовпадение типов | No effect | Замена не применяется; сохраняйте стоковый тип. |
| `BLK invalid ... (type real)` | Контекст парсера/падения | Неверный числовой текст | Crashes game | Наблюдалось при нескольких параметрах без разделителя в одной строке. |
| `load bomb properties from 'mod:...'` | Загрузка миссии | Локальный файл бомбы прочитан | Unverified (in files only) | В проверенном случае последующее визуальное изменение доказало игровой эффект. |

В изученных логах действовал повторяющийся XOR-ключ длиной 768 байт. Выводите предполагаемый ключ из достаточно большого лога, сверяйте структуру текста и долю управляющих байтов и не считайте ключ неизменным для будущих версий. Логи хранятся ограниченное время, поэтому версию игры и игровое наблюдение лучше фиксировать отдельно.
