# Перечитывание файлов и кэш

Наблюдения относятся к работающей игре и повторной загрузке пользовательской миссии. Они не доказывают очистку всех внутренних кэшей. Строка `include` в логе подтверждает разбор файла; правки орудия и бомбы также дали видимый эффект в игре.

| Файл или путь | Где находится | Тип / единицы | Статус | Наблюдение |
|---|---|---|---|---|
| `UserMissions/*.blk` | Папка пользовательских миссий | текстовый BLK | Verified in game | Изменённое имя миссии прочитано при следующей загрузке в той же сессии. |
| Копия машины | `content/pkg_local/gameData/{flightModels,units/tankModels,units/ships}/*.blk` | текстовый BLK | Verified in game | Новые и изменённые копии загружались без перезапуска игры. |
| Копия орудия | `gameData/Weapons/groundModels_weapons/*.blk` в `pkg_local` | текстовый BLK | Verified in game | Изменение длины сердечника в уже использованной копии изменило пробитие после перезагрузки миссии. |
| Копия бомбы | `gameData/Weapons/BombGuns/*.blk` в `pkg_local` | текстовый BLK | Verified in game | Изменение `explosionFx` наблюдалось после перезагрузки миссии. |
| Новый пресет | `gameData/flightModels/weaponPresets/*.blk` в `pkg_local` | текстовый BLK | Verified in game | Новый пресет загружался при работающей игре. |
| Изменённый ранее использованный пресет | там же | текстовый BLK | Unverified (in files only) | Повторные строки `include` указывают на перечитывание; отдельного визуального сравнения нет. |
| Новые копии ракеты и торпеды | `gameData/Weapons/{rocketGuns,torpedoes}/*.blk` в `pkg_local` | текстовый BLK | Verified in game | Обе новые копии загрузились без перезапуска. Повторная правка не проверялась отдельно. |
| `UserMissions/usr_<mission>.csv` | Рядом с миссией | UTF-8 CSV с `;` | Verified in game | Новые названия появились после перезапуска игры; одной перезагрузки миссии оказалось мало. |

Имена управляемых копий можно сохранять. После изменения игрового BLK перезагрузите миссию. После создания или изменения CSV локализации перезапустите игру. После обновлений игры эти правила следует перепроверять.
