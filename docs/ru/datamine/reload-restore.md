# Перезарядка и пополнение боезапаса

| Утверждение | Доказательство |
|---|---|
| Время перезарядки орудия = `1 / shotFreq` в копии файла орудия (танковые пушки: 1 с, 0,05 с; ручное заряжание 0,5 с экипаж не перебивает). Темп авиапушки меняется так же. | Проверено в игре |
| Действие миссии `unitRestore` пополняет боезапас: каждые N секунд, полностью или после уничтожения цели; при 1 с / 0,5 с орудие стреляет почти без остановки. По нажатию огня — мгновенная перезарядка. | Проверено в игре |
| Условия миссии на остаток боезапаса нет — «пополнить, когда кончился» напрямую не задать. | Только в файлах (такого условия среди условий миссий нет) |
