# Лётные модели и подвеска

Файл самолёта находится в `gameData/flightModels/<машина>.blk`; `fmFile` может ссылаться на общую ЛМ в `flightModels/fm/`. Не предполагайте совпадения имени ЛМ и машины. Схемы двигателя различаются: `EngineN` может содержать параметры сам или ссылаться через `Type` на `EngineTypeN`. Правка общего типа затрагивает оба двигателя.

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| Машина `fmFile` | Ссылка на лётную модель | путь | Unverified (in files only) |
| ЛМ `Mass/EmptyMass` | Масса пустого самолёта; правка влияла на полёт и компенсировала подвеску | кг | Verified in game |
| ЛМ `Mass/Takeoff` | Указанная взлётная масса; проверенное уменьшение не дало видимого эффекта | кг | No effect |
| ЛМ `Mass/AdvancedMass`, `Parts`, `PartsWithSurface` | Представление распределённой массы | разные | Unverified (in files only) |
| ЛМ `EngineTypeN/Main/Power`, `Compressor/Power0` | Поля мощности; оба меняли разгон поршневого самолёта | единицы исходника | Verified in game |
| Машина `WeaponSlots/WeaponSlot/index`, `WeaponPreset/Weapon/blk`, `emitter` | Слот, вариант, оружие и точка крепления | индекс/путь | Verified in game |
| Машина `weapon_presets/preset/blk` → `flightModels/weaponPresets/*.blk` | Старая схема пресета всей машины, иногда с прямым списком `Weapon` | путь | Verified in game |
| `WeaponSlots/maxloadMass*`, `maxDisbalance`, `BannedWeaponPreset` | Заявленные пределы массы и сочетаний | кг для массы, прочее по исходнику | Unverified (in files only) |

Свои сочетания `(slot, preset)` и старый прямой список `Weapon` работали в игре. Миссия разрешала сочетания сверх указанных пределов массы и перекоса; эти пределы следует показывать как предупреждения. Номер слота не всегда определяет сторону, а поведение вертолётов требует отдельных проверок.

«Невесомая подвеска» использует копию ЛМ: `EmptyMass` уменьшается на массу подвески, а `fmFile` копии машины указывает на неё. В проверенном случае это компенсировало тяжёлую бомбу в полёте. Нельзя допускать неположительный результат; модели с `AdvancedMass` и вертолёты не проверены. Неизменная копия подразумевает меньшую пустую массу после сброса, но отдельно в полёте это не проверяли. Проверенные правки `bomb/dragCx` и `Weapon/dragCx` не дали видимого эффекта в измеренном сценарии.
## Карта полей лётной модели

| Путь или поле | Где находится | Смысл / тип или единицы | Статус | Наблюдение |
|---|---|---|---|---|
| `fmFile` | Корневой BLK самолёта | Путь к ЛМ, строка | Verified in game | Копия машины использовала копию ЛМ и изменённую массу. Многие машины разделяют ЛМ, поэтому имя файла нельзя угадывать. |
| `Mass/EmptyMass` | `flightModels/fm/*.blk` | Пустая масса, кг | Verified in game | Копия ЛМ изменила измеренный полёт и компенсировала проверенную подвеску. |
| `Mass/Takeoff` | ЛМ | Указанная взлётная масса, кг | No effect | Проверенное уменьшение не изменило измеренный полёт сверх разброса контроля. |
| `Mass/{MaxFuelMass0,OilMass,AdvancedMass}` | ЛМ | Массы топлива/масла в кг и булев режим | Unverified (in files only) | Есть в стоке; действие локальной правки отдельно не проверено. |
| `Mass/{Parts,PartsWithSurface}` | ЛМ | Части с массой и связями с моделью повреждений | Unverified (in files only) | Их сумма не обязана равняться `EmptyMass`; компенсация при расширенной схеме масс не проверена. |
| `Mass/{CenterOfGravity,MaxFuelMassExternal0}` | ЛМ | Точка / кг | Unverified (in files only) | Есть в стоковых ЛМ; действие локальной правки отдельно не проверено. |
| `MomentOfInertia` | Корень ЛМ, вне `Mass` | Три компонента инерции | Unverified (in files only) | Компенсация подвески не меняет это поле. |
| `EngineN/Type` → `EngineTypeN` | ЛМ | Ссылка на общий тип двигателя | Unverified (in files only) | Общий тип меняет все двигатели, которые на него ссылаются. Часть ЛМ хранит значения прямо в `EngineN`. |
| `EngineTypeN/Main/Power` | ЛМ | Мощность поршневого двигателя, единицы источника | Verified in game | Проверенное увеличение изменило разгон. |
| `EngineTypeN/Main/{Type,Thrust,ThrustMax,RPMMax}` | ЛМ | Вид и выходные поля двигателя, единицы источника | Unverified (in files only) | Есть в стоке; `Thrust` нельзя автоматически считать рабочим регулятором поршневого двигателя. |
| `EngineTypeN/Compressor/{Power0,Altitude0,Ceiling0}` | ЛМ | Высотная характеристика мощности | Verified in game | Проверенная правка `Power0` изменила полёт; остальные точки отдельно не проверялись. |
| `EngineTypeN/Main/ModeN`, `ThrustMax/*`, `Afterburner/*` | ЛМ | Режимы газа, таблица тяги и форсаж | Unverified (in files only) | Есть у многих реактивных и турбовинтовых ЛМ; последствия локальных правок не изолированы. |
| `PropellerN`, `PropellerTypeN`, `TransmissionN`, `NozzleN` | ЛМ | Винты, привод и сопла | Unverified (in files only) | Часть двигателей использует эти ссылки; единой схемы нет. |

В измеренном сравнении за 30 секунд уменьшение `EmptyMass` на массу проверенной подвески приблизило полёт к пустой машине; без компенсации та же подвеска значительно утяжеляла самолёт. Правка `Takeoff` не изменила разгон и высоту сверх разброса контроля. Точный учёт сопротивления подвески, центра тяжести и расширенной схемы масс остаётся открытым. См. [Пилоны](pylons.md).
