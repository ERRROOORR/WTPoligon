# BLK: бинарный и текстовый формат

BLK — дерево именованных блоков и типизированных параметров. Бинарный файл внутри VROMFS может хранить имена локально (FAT) либо ссылаться на общую таблицу `?nm` архива (SLIM); бывают варианты со zstd и словарём. Текстовый BLK используется для локальных копий и миссий. Сохраняйте порядок и повторяющиеся имена: правка может адресовать конкретное вхождение.

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| Вид бинарного BLK `1`, `3`, `4`, `5` | Наблюдавшиеся FAT, SLIM и сжатые SLIM | код | Unverified (in files only) |
| `?nm` / локальные имена BLK | Общая или собственная таблица имён | — | Unverified (in files only) |
| `name:t="text"` | Строка | — | Unverified (in files only) |
| `name:i`, `name:i64`, `name:b` | Целое 32/64 бита, логическое (`yes`/`no`) | значение | Unverified (in files only) |
| `name:r`, `name:c`, `name:m` | Вещественное число, цвет, матрица | значение | Unverified (in files only) |
| `name:p2/p3/p4`, `name:ip2/ip3/ip4` | Векторы вещественных или целых значений | значение | Unverified (in files only) |

В текстовом BLK заключайте в кавычки имена со специальными символами, пишите один параметр в строке и экранируйте строки через `~` (`~"`, `~~`, `~n`). Обратная косая черта не экранирует строку. При замене сохраняйте тип параметра. Разбор бинарного формата и круговая запись текста сверены на исследованных файлах; это само по себе не доказывает влияние поля в игре.
