# Пользовательские миссии и техника

BLK одиночной пользовательской миссии лежит в `UserMissions/`. Блок юнита называется `armada` для самолёта или вертолёта, `tankModels` для наземной техники, `ships` для флота. `unit_class` выбирает машину; `mission_settings/mission/name` задаёт идентификатор миссии. Соответствующий `usr_*.csv` может содержать названия (см. [Локализацию](localization.md)).

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| `UserMissions/*.blk` | Файл пользовательской миссии | — | Verified in game |
| `armada`, `tankModels`, `ships` / `unit_class` | Категория и выбранная машина | — | Verified in game |
| `mission_settings/mission/name` | Идентификатор миссии для локализации | — | Verified in game |
| `pkg_local/gameData/flightModels/`, `units/tankModels/`, `units/ships/` | Папки локальных копий машин | — | Verified in game |
| `userVehicles/<машина из ангара>` | Запуск принадлежащей игроку машины | — | Verified in game |
| `UserMissions/usr_<миссия>.csv` | Текст миссии и копии, читается при запуске игры | — | Verified in game |

Настоящее имя принадлежащей игроку машины сохраняет её обычный тип и интерфейс. У принадлежащего игроку вертолёта `userVehicles/` также сохранил вертолётный интерфейс со штатным пресетом, но оборудование наземной техники из модификаций перенеслось не полностью. Для машины вне ангара требуется отдельное имя локальной копии; она может ездить и стрелять, но терять интерфейс, оборудование, подписи боеприпасов или действие модификаций. Копия вертолёта под новым именем получила самолётный интерфейс. Добавление имени своего пресета только в `userVehicles/` не сработало: игра обратилась к стоковому каталогу пресетов. Поэтому «любая техника» не означает полного совпадения со штатной машиной.
