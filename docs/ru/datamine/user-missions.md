# Пользовательские миссии и техника

BLK одиночной пользовательской миссии лежит в `UserMissions/`. Блок юнита называется `armada` для самолёта или вертолёта, `tankModels` для наземной техники, `ships` для флота. `unit_class` выбирает машину; `mission_settings/mission/name` задаёт идентификатор миссии. Соответствующий `usr_*.csv` может содержать названия (см. [Локализацию](localization.md)).

| Путь или поле | Смысл | Единицы | Статус |
|---|---|---|---|
| `UserMissions/*.blk` | Файл пользовательской миссии | — | Verified in game |
| `armada`, `tankModels`, `ships` / `unit_class` | Категория и выбранная машина | — | Verified in game |
| `mission_settings/mission/name` | Идентификатор миссии для локализации | — | Verified in game |
| `pkg_local/gameData/flightModels/`, `units/tankModels/`, `units/ships/` | Папки локальных копий машин | — | Verified in game |
| `userVehicles/<машина из ангара>` | Запуск принадлежащей игроку машины | — | Verified in game |
| `UserMissions/usr_<миссия>.csv` | Текст миссии и копии, читается при запуске игры | — | Verified in game |

Настоящее имя принадлежащей игроку машины сохраняет её обычный тип и интерфейс. У принадлежащего игроку вертолёта `userVehicles/` также сохранил вертолётный интерфейс со штатным пресетом, но оборудование наземной техники из модификаций перенеслось не полностью. Для машины вне ангара требуется отдельное имя локальной копии; она может ездить и стрелять, но терять интерфейс, оборудование, подписи боеприпасов или действие модификаций. Копия вертолёта под новым именем получила самолётный интерфейс. Добавление имени своего пресета только в `userVehicles/` не сработало: игра обратилась к стоковому каталогу пресетов. Поэтому «любая техника» не означает полного совпадения со штатной машиной.
## Поля миссии и запуска

| Путь или поле | Где находится | Смысл / тип | Статус | Наблюдение |
|---|---|---|---|---|
| `mission_settings/mission/{name,locName,locDesc}` | BLK миссии | Идентификатор, название и описание | Verified in game | `name` связывает миссию с локализацией; буквальное название показывалось. |
| `units/armada`, `units/tankModels`, `units/ships` | BLK миссии | Блоки семейств юнитов | Verified in game | Проверенные миссии самолёта, танка и корабля загружались в своих блоках. |
| `unit_class` юнита | Блок юнита миссии | Идентификатор машины, строка | Verified in game | Стоковое имя работает для техники из ангара; недоступная машина под стоковым именем зависит от владения и каталога. |
| `weapons`, `bullets0..3`, `bulletsCount0..3` юнита | Блок юнита миссии | Пресет, ключи и количество снарядов | Verified in game | Проверенные миссии выбирали подвеску и БК без отдельного меню выбора в миссии. |
| `userVehicles/<машина из ангара>` | `content/pkg_local` | Слот со стоковой идентичностью | Verified in game | Со стоковым пресетом сохранился HUD вертолёта; оборудование модификаций перенеслось не полностью. |
| Отдельная копия в `gameData/flightModels`, `units/tankModels` или `units/ships` | `content/pkg_local` | Новая идентичность машины | Verified in game | Запускала недоступную технику с указанными выше ограничениями интерфейса и оборудования. |
| Поиск в каталоге `char.vromfs.bin` | Стоковый архив | Идентичность, доступ и ссылки пресетов | Verified in game | Локальная копия не заменила запись стокового каталога и не сделала новый пресет доступным только через `userVehicles`. |
| `crewSkillK`, `props/uniqueName` юнита | BLK миссии | Возможный множитель навыка и ключ имени бота | Unverified (in files only) | Есть в стоковых миссиях; отдельное влияние для игрока не установлено. |

Сценарий может добавить наземные и воздушные цели, маршруты, условия и триггеры восстановления. Наличие этих конструкций в BLK само по себе не доказывает поддержку каждого предлагаемого сочетания сценария. См. [обзор программы](../program/overview.md).
