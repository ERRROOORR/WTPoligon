# Сведения из CDK

[Руководство War Thunder CDK по созданию своей техники](https://wiki.warthunder.com/cdk/1212-custom-units-creation) описывает добавление записи `weapon_presets/preset` через override, отдельный BLK пресета и скрытие неиспользуемых узлов пилонов через `hideNodes`. Вертолёты там относятся к семейству `flightModels`. Руководство подтверждает структуру файлов, но его пример собственной модели не доказывает пригодность всех придуманных сочетаний для любой стоковой машины.

| Путь или поле | Где находится | Смысл / тип | Статус | Наблюдение |
|---|---|---|---|---|
| `weapon_presets/preset` | BLK самолёта | Ссылка на пресет целой машины | Unverified (in files only) | Описана в CDK и найдена в стоковых файлах. Отдельные свои копии затем проверялись в игре. |
| `flightModels/weaponPresets/*.blk` | Файл пресета | Список оружия или выбор слотов | Unverified (in files only) | CDK использует отдельный файл; при адаптации нужно сохранять реальную стоковую форму. |
| Пресет `hideNodes` | BLK пресета | Видимость узлов модели | Unverified (in files only) | CDK показывает скрытие пустых пилонов. Геометрию конкретного узла нужно смотреть в модели или игре. |

См. [Подвеска](pylons.md): там разделены старая и новая схемы и приведены результаты игровых проверок.
