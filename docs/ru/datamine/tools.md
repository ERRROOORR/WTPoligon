# Открытые инструменты и источники

Это внешние материалы для изучения форматов и сравнения результатов парсеров. Они не входят в репозиторий. Перед использованием проверяйте лицензии проектов и актуальное поведение инструментов.

| Проект | Для чего полезен | Что подтверждено исследованием |
|---|---|---|
| [WTOSF `wt_ext_cli`](https://github.com/Warthunder-Open-Source-Foundation/wt_ext_cli) | Распаковка VROMFS и эталон текстового BLK | Сырые файлы всех изученных архивов совпали побайтно; большинство деревьев BLK совпало. У изученной версии текстовый вывод имел несколько ошибок кавычек, порядка каналов цвета и формата `ip4`. |
| [WTOSF `wt_blk`](https://github.com/Warthunder-Open-Source-Foundation/wt_blk) | Независимая реализация BLK | Помогает сверять типы значений и варианты бинарного формата. |
| [DagorEngine](https://github.com/GaijinEntertainment/DagorEngine) | Парсер текстового BLK и директивы | `blk_parser.cpp`, `blk_core.cpp` и код записи объясняют `include`, номера одноимённых полей, типы и экранирование строк через `~`. |
| [War Thunder Datamine](https://github.com/gszabi99/War-Thunder-Datamine) | Публичная история извлечённых определений | Позволяет отслеживать изменения версий игры; этот репозиторий не перепубликует файлы датамайна. |
| [WTFTD](https://github.com/StonewarP/WTFTD-War_Thunder_Full_Test_Drive) | Расчёты пробития сообщества | Реализация формул сопоставлена с наблюдениями пробития в игре; крайние случаи ещё требуют проверки. |

Изученные архивы клиента имели `VRFx` и режим упаковки `0x30`; 35 568 файлов совпали с независимой сырой распаковкой. Бинарный парсер BLK прошёл круговую проверку на 31 647 файлах. Совпадение разбора подтверждает понимание формата для этой версии игры, но не влияние игрового поля. См. [VROMFS](vromfs.md), [BLK](blk.md) и [Логи](game-logs.md).
