# Ядерные заряды

Как игра решает, что взрыв ядерный, и как дать это другим боеприпасам.

| Утверждение | Доказательство |
|---|---|
| У штатных ядерных бомб в `bomb{}` есть `yield` (килотонны); полный ядерный взрыв (вспышка, гриб) рисуется по одному `yield` — `nuclearExplosionFx` необязателен (у некоторых вариантов 5 кт — `explosion_massive` и `createVolumetricCloud:b=no`). | Проверено в игре |
| Любая **бомба** или **ракета/ПТУР/ЗУР** становится ядерной (урон и вид): в её блоке `bomb{}` / `rocket{}` — `yield:r=<кт>`, `explosiveType:t="tnt"`, `explosiveMass:r=20000`, `pressureDamage{ damageType:t="pressure" }`. | Проверено в игре |
| **Снаряд пушки** (`bullet{}`) с теми же полями — урон ядерный, взрыв обычный; только `yield`+`pressureDamage` — обычный фугас. | Проверено в игре |
| Снаряд пушки становится полностью ядерным, если это **неуправляемая `bullet{ rocket{…} }`** с рецептом выше. | Проверено в игре |
| Самолёт, используемый как бомба (составной самолёт, см. [самолёты-бомбы](bomb-planes.md)): рецепт в его `warhead{}` даёт только ядерный **урон** — гриба нет ни с явным `nuclearExplosionFx`, ни без. | Проверено в игре |

Правки — в копии файла оружия (`include` штатного файла + изменённый блок); штатный файл не трогается.
