# Пилоны и пресеты авиации

В исследованных BLK авиации две пересекающиеся схемы. В изученном архиве 827 машин имели только старый список `weapon_presets`, 821 — и его, и `WeaponSlots`, ни одной машины только со слотами, ещё четыре не попали в эти группы. Файл стокового пресета может выбирать пары `(slot,preset)`, перечислять `Weapon` напрямую или не содержать верхнего `Weapon`. Исходную форму и порядок нужно сохранять.

| Путь или поле | Где находится | Смысл / тип или единицы | Статус | Наблюдение |
|---|---|---|---|---|
| `WeaponSlots/WeaponSlot/index` | BLK самолёта | Номер слота, целое | Verified in game | Свои сочетания `(slot,preset)` загружались. По арифметике индексов нельзя определить стороны. |
| `WeaponSlot/WeaponPreset/name` | BLK самолёта | Имя варианта, строка | Verified in game | Миссия выбирает определённый вариант; новое имя должно быть определено в копии машины. |
| `WeaponPreset/Weapon/{trigger,blk,emitter,bullets}` | BLK самолёта | Группа управления, путь к оружию, точка, количество | Verified in game | Своё оружие крепилось и применялось через эти записи. Вариант может содержать несколько блоков `Weapon`. |
| `WeaponPreset/{ShowNodes,HideNodes}` | BLK самолёта | Видимость узлов модели | Unverified (in files only) | Многие стоковые варианты переключают узлы; геометрию надо проверять на модели. |
| `WeaponPreset/{DependentWeaponPreset,BannedWeaponPreset,reqModification}` | BLK самолёта | Зависимости, запреты, ключ улучшения | Unverified (in files only) | Есть в стоковых данных; миссия приняла сочетания сверх перечисленных ограничений. |
| `WeaponSlots/{maxloadMass,maxloadMassLeftConsoles,maxloadMassRightConsoles,maxDisbalance}` | BLK самолёта | Пределы массы и перекоса, кг где применимо | Unverified (in files only) | Загрузка миссии их не проверяла. Масса и перекос всё же влияют на полёт. |
| `WeaponSlot/{tier,order,notUseforDisbalanceCalculation}` | BLK самолёта | Порядок и флаг расчёта перекоса | Unverified (in files only) | У части слотов нет `tier` или `order`; точные правила игры не установлены. |
| `Weapon/{external,separate,machLimit,mass,dragCx}` | Вариант или пресет | Смешанные флаги, пределы, масса | Unverified (in files only) | Поля есть на уровне оружия; `Weapon/mass` нельзя приравнивать к массе боеприпаса. Проверка `Weapon/dragCx` не дала видимого эффекта. |
| `weapon_presets/preset/{name,blk}` | BLK самолёта | Пресет целой машины и путь | Verified in game | Прямой список оружия старой схемы работал у проверенного самолёта. |
| Пресет `Weapon/{slot,preset}` | `flightModels/weaponPresets/*.blk` | Выбор слота | Verified in game | Свои сочетания загружались, если их имена были определены в копии машины. |
| Пресет `Weapon/{trigger,blk,emitter,bullets}`, `hideNodes` | там же | Прямой список старой схемы и видимость узлов | Verified in game | Прямые списки работали; пустые списки и настройки узлов нужно сохранять. |

Один `emitter` может встречаться с разным оружием в разных стоковых пресетах. Это даёт примеры, но не универсальную совместимость. Смешивание записей разных пресетов у старых машин полностью не проверено. Вертолёты используют то же семейство файлов: одни имеют слоты, другие только пресеты целой машины. Контейнер может содержать несколько видов оружия, а `Weapon/mass` может описывать массу установки. Копия вертолёта под новым именем показывала самолётный HUD; вертолёт из ангара через `userVehicles/` сохранял вертолётный HUD со стоковым пресетом.

В проверенных сочетаниях миссия не применяла пределы общей массы, массы консолей, перекоса и `BannedWeaponPreset`. Их нужно показывать как предупреждения, поскольку масса и перекос всё же влияют на полёт. Зеркальную точку подтверждают имена, видимость узлов, модель или проверка в игре; правило `index + 1` неверно как общее.

У проверенного самолёта копия ЛМ с уменьшенным на массу подвески `Mass/EmptyMass` позволила лететь с очень тяжёлой бомбой примерно как без неё. Итоговая пустая масса должна быть положительной. `AdvancedMass=yes`, поведение центра тяжести и вертолёты требуют отдельной проверки. Неизменная копия ЛМ подразумевает меньшую пустую массу и после сброса, но это следствие не проверялось отдельно в полёте. Правки `Mass/Takeoff`, `bomb/dragCx` и `Weapon/dragCx` не дали искомого эффекта в проверенных сценариях. См. [Неудачные подходы](failures.md).

## Детали обзора и правила сборки

В исследованном архиве просмотрены 1 652 корневых файла авиации и 9 815 файлов пресетов. Среди последних 7 525 использовали только записи `(slot,preset)`, 1 691 содержали прямые `Weapon/blk`, а 599 не имели верхнего `Weapon`. Это формы данных, а не последовательные эпохи: у 821 машины одновременно были старый каталог и слоты. Две ссылки на старые пресеты в изученном архиве не разрешились, поэтому при отсутствии файла нужно сообщать об ошибке, а не придумывать путь.

| Путь или поле | Где находится | Смысл / тип или единицы | Статус | Наблюдение |
|---|---|---|---|---|
| `WeaponSlots/HideNodes` | BLK самолёта | Изначально скрытые узлы | Unverified (in files only) | Стоковые варианты могут показывать пилоны через `ShowNodes`; регистр имени сохраняют. |
| `WeaponPreset/{iconType,showInWeaponMenu}` | Вариант слота | Данные меню | Unverified (in files only) | Есть у многих, но не всех стоковых вариантов; сами по себе не доказывают пригодность оружия. |
| `WeaponPreset/Weapon/{external,separate,machLimit,mass}` | Вариант слота | Флаги крепления, предел Маха, возможная масса | Unverified (in files only) | `mass` этого уровня может быть массой установки, особенно у вертолёта. |
| Пресет `weaponConfig`, `tags` | `weapon_presets/preset` машины | Данные целого пресета | Unverified (in files only) | Есть у части старых записей; при клонировании известного пресета их сохраняют. |
| Пресет `hideNodes`, `hideDmParts` | Файл пресета | Видимость геометрии и частей повреждений | Unverified (in files only) | Даже пресет без оружия может иметь важные настройки узлов. |
| `reqModification` | Вариант слота, оружие или старый пресет | Требование улучшения | Unverified (in files only) | Тот же ключ находится в модификациях машины и общих данных стоимости; точное правило в пользовательской миссии не изолировано. |
| `Weapon/emitter` | Вариант слота или прямой пресет | Точка крепления/выпуска модели | Unverified (in files only) | Одна точка встречается с разным оружием в разных стоковых пресетах. Имя не доказывает геометрию. |

Для копии старой схемы сохраняют прямой список `Weapon` с `trigger`, `blk`, `emitter`, `bullets`, порядок и `hideNodes`. Пустой список может означать отсутствие внешней подвески при сохранении встроенных пушек. Для схемы слотов каждый новый `WeaponPreset/name` определяют в копии самолёта, а отдельный файл пресета ссылается на эти точные имена. Новое имя только в `userVehicles/` не заработало, потому что поиск шёл по стоковому каталогу. В проверенном старом пресете удалось заменить ссылку одной бомбы, сохранив остальные три.

Зеркалирование нельзя строить по общей формуле номера слота. Имена сторон, `ShowNodes` и `emitter` дают подсказки; у многих старых машин точки пронумерованы без стороны. Вариант вертолёта может содержать контейнер и несколько записей оружия; нужно сохранить их `trigger`, порядок и возможную массу установки. Проверенная своя комбинация слотов вертолёта работала под новым именем копии, но показывала самолётный HUD.
