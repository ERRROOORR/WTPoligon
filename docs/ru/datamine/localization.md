# Локализация

Локальный для миссии файл `usr_<миссия>.csv` может назвать миссию, копии техники и оружия без подмены общей папки `lang` игры. Положите CSV рядом с миссией в `UserMissions/`; основа имени должна соответствовать идентификатору миссии. CSV использует точку с запятой, заголовок языков и UTF-8. В штатных CSV много языковых столбцов; в небольшом CSV миссии достаточно нужных. Проверяйте фактический язык клиента.

| Путь или ключ | Смысл | Единицы | Статус |
|---|---|---|---|
| `mission_settings/mission/name` | Идентификатор, связанный с CSV миссии | — | Verified in game |
| `UserMissions/usr_<миссия>.csv` | Пользовательская локализация; читается при запуске игры | — | Verified in game |
| `missions/<миссия>` | Название в списке миссий | текст | Verified in game |
| `<копия>_1` | Название копии машины в боевых сообщениях | текст | Verified in game |
| `<копия>_shop`, `<копия>_0`, `<копия>_2`, `<копия>/date` | Другие ключи карточки; вклад каждого не выделен отдельно | текст | Unverified (in files only) |
| `weapons/<копия оружия>/short` | Краткое имя копии ракеты/пусковой | текст | Verified in game |
| Оружие `bullet/bulletName` → ключ CSV | Название копии снаряда | текст | Verified in game |

CSV локализации читается при запуске игры: после добавления или изменения имён перезапустите клиент. У миссий и правленых BLK другой порядок перечитывания. При отсутствии ключа может показываться служебное имя. Название миссии и карточка машины были локализованы, но точный ключ карточки среди нескольких добавленных одновременно не установлен.
## Построение ключей и границы

| Путь или ключ | Где находится | Смысл / тип | Статус | Наблюдение |
|---|---|---|---|---|
| `missions/<миссия>` | CSV пользовательской миссии | Название миссии, UTF-8 | Verified in game | Локализовалось после перезапуска игры. |
| `<машина>_1` | CSV пользовательской миссии | Имя машины в журнале боя и списке игроков | Verified in game | Проверенный танк-копия получил имя; копия самолёта без ключа сохранила служебное имя. |
| `<машина>_shop`, `_0`, `_2`, `/date` | CSV пользовательской миссии | Варианты для магазина, карточки, класса и даты | Unverified (in files only) | Карточка локализовалась при нескольких добавленных ключах; вклад каждого отдельно не установлен. |
| `weapons/<оружие>/short` | CSV пользовательской миссии | Краткое имя копии ракеты | Verified in game | Появилось на HUD подвески и в журнале боя после перезапуска. |
| `bullet/bulletName` | BLK копии орудия | Ключ текста копии снаряда | Verified in game | Новое значение и запись CSV дали имя проверенному снаряду в журнале боя. |
| `locName`, `locDesc` | `mission_settings/mission` | Название/описание миссии или ключ локализации | Unverified (in files only) | Обычный текст поддерживается; поиск по ключу отдельно не проверен. |
| `uniqueName` | Свойства юнита миссии | Ключ имени бота/экипажа | Unverified (in files only) | Стоковые примеры указывают на имя бота, а не замену имени машины. |

В CSV используются `;` и заголовок со столбцами языков. Минимальный файл может содержать английский и русский столбцы; кавычки CSV нужно экранировать. Основа имени миссии, `mission_settings/mission/name` и `usr_<миссия>.csv` должны совпадать. CSV миссии позволяет не заменять глобальную папку `lang`. Отсутствующий ключ может показаться как идентификатор; каждой именованной копии нужна запись `_1`.
