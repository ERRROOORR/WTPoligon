# WT Poligon Beta-1.0 — чек-лист тестера

Запуск: распаковать архив, `run.bat`. Игра должна быть установлена (программа находит её сама или спросит папку).
После записи миссия в игре: **Одиночные миссии → Пользовательские → «WTP5 — <машина>»**. Перезапуск игры не нужен.
Если что-то пошло не так — «Проверка и запись» → **«Логи»** (справа внизу) и пришлите архив из папки `logs`.

Отметьте ✅/❌ и коротко, что видели. 📄 — пункты, которые мы сами ещё не проверяли в игре (важнее всего).

## 1. Техника
- [ ] Поиск находит машину по-русски, по-английски, с опечаткой, в неверной раскладке.
- [ ] Машина из ангара: отметка «есть в ангаре» → миссия запускается под настоящим именем.
- [ ] Машина не из ангара: миссия запускается копией.

## 2. Подвеска (самолёт/вертолёт)
- [ ] Штатный пресет и своя подвеска; оружие видно, пускается/сбрасывается.
- [ ] «Любое оружие игры» на пилон (например ЗУР танка на F-15C) — пускается, наводится.
- [ ] Невесомая подвеска — тяжёлая бомба не утяжеляет самолёт.

## 3. Характеристики
- [ ] Двигатель: мощность/тяга ×2 — заметно быстрее разгон.
- [ ] 📄 Тяга на форсаже — меняется ли разгон на форсаже.
- [ ] Масса: меньше — быстрее набор скорости/высоты.
- [ ] РЛС: «Дальность обнаружения» меньше — цель видна ближе.
- [ ] 📄 РЛС: «Обзор по азимуту/углу места», «Ширина луча» — меняется ли сектор поиска на индикаторе.
- [ ] Ловушки: «Всего зарядов» — сколько ловушек в бою.

## 4. Боеприпасы 📄
- [ ] Боекомплект из 4 ячеек — в бою те снаряды и столько штук.
- [ ] «+» — добавить снаряд от другого орудия/машины, поставить в ячейку — стреляет им.
- [ ] Правка массы/ВВ/скорости снаряда — заметна (пробитие, разрыв, траектория).
- [ ] Самолёт: другая лента, патронов на ствол.

## 5. Сценарий 📄
- [ ] Наземка: мишени на дистанции, «стреляют по вам», цели возвращаются.
- [ ] Самолёт: боты на 3/10/30 км, РЛС бота, высота воздушных целей, высота и скорость старта.
- [ ] Вертолёт: старт с земли.
- [ ] Флот: корабли-цели, «плывут».
- [ ] Дуэль: противник, его подвеска, дистанция до 200 км.
- [ ] Карта, время суток, погода, режим игры, маркеры, бесконечное топливо, пополнение БК, быстрая перезарядка.

## 6. Проверка и запись
- [ ] Ошибки показываются до записи и понятны.
- [ ] «Откатить эту машину» / «Откатить всё» — в игре не остаётся миссий и файлов программы.
- [ ] «Логи» — архив создаётся, папка открывается.

Окно не должно подвисать при смене машины и шагов — если подвисает, напишите где.
