# WT Poligon 2.0-beta — чек-лист тестера

Запуск: распаковать архив, запустить `run.bat`. Игра должна быть установлена: программа находит её сама или
спрашивает папку.

- Миссия в игре: **Одиночные миссии → Пользовательские → «WTP5 — <машина>»**. Перезапуск игры не нужен.
- При ошибке: «Проверка и запись» → **«Логи»** (справа внизу), пришлите архив из папки `logs`.

Отметьте ✅/❌ и коротко, что видели. 📄 — пункты, которые в игре ещё не проверялись; они важнее всего.

## 1. Техника
- [ ] Поиск находит машину по-русски, по-английски, с опечаткой, в неверной раскладке.
- [ ] Машина из ангара: отметка «Есть в моём ангаре» → миссия запускается под настоящим именем.
- [ ] Машина не из ангара: миссия запускается копией.
- [ ] «Сохранить как свою технику» → «Открыть свою технику»: настройки на месте; сохранённая машина есть в поиске.

## 2. Подвеска (самолёт/вертолёт)
- [ ] Штатный пресет и своя подвеска: оружие видно, пускается/сбрасывается.
- [ ] «Любое оружие игры» на пилон (например, ЗУР танка на F-15C): пускается, наводится.
- [ ] Невесомая подвеска: тяжёлая бомба не утяжеляет самолёт.
- [ ] Контейнер с ракетами (×2, ×4) на чужом пилоне: в бою все ракеты.
- [ ] 📄 Mistel из окна: самолёт под подвеской (например, Су-27), взрывчатка или ядерная БЧ — отцепляется, взрывается.

## 3. Характеристики
- [ ] Двигатель: мощность/тяга ×2 — разгон заметно быстрее.
- [ ] 📄 Тяга на форсаже: меняется ли разгон на форсаже.
- [ ] Масса: меньше — быстрее набор скорости/высоты.
- [ ] РЛС: «Дальность обнаружения» меньше — цель видна ближе; шкала и зона отображения меняются вместе.
- [ ] РЛС: обзор по азимуту и углу места — сектор поиска на индикаторе меняется, в том числе в ближнем бою.
- [ ] Ловушки: «Всего зарядов» — сколько ловушек в бою.
- [ ] «Перезарядка»: время перезарядки в бою совпадает с заданным.

## 4. Боеприпасы 📄
- [ ] Боекомплект из 4 ячеек: в бою те снаряды и в том количестве.
- [ ] «+»: снаряд от другого орудия/машины в ячейке — стреляет им.
- [ ] Правка массы/ВВ/скорости снаряда заметна (пробитие, разрыв, траектория).
- [ ] «Ядерный заряд» у бомбы, ракеты, снаряда: ядерный взрыв.
- [ ] Самолёт: другая лента, патронов на ствол.

## 5. Вызываемая техника 📄
- [ ] Самолёт как дрон машины: вызывается, летит, стреляет.
- [ ] Танки / пусковые ЗРК в сопровождении: появляются, количество как задано.
- [ ] Своя сохранённая техника в вызове: с её подвеской.

## 6. Сценарий 📄
- [ ] Наземка: мишени на дистанции, «стреляют по вам», цели возвращаются.
- [ ] Самолёт: боты на 3/10/30 км, РЛС бота, высота воздушных целей, высота и скорость старта.
- [ ] Вертолёт: старт с земли.
- [ ] Флот: корабли-цели двигаются.
- [ ] Дуэль: противник, его подвеска, дистанция до 200 км.
- [ ] Карта, время суток, погода, режим игры, маркеры, бесконечное топливо.
- [ ] «Пополнять боезапас»: после того как всё выпущено, боезапас возвращается (самолёт, танк).
- [ ] Полигон: отъехать/отлететь на 10–60 км — появляется ли «Вернитесь на поле боя».

## 7. Проверка и запись
- [ ] Ошибки показываются до записи и понятны.
- [ ] «Откатить эту машину» / «Откатить всё»: в игре не остаётся миссий и файлов программы.
- [ ] «Логи»: архив создаётся, папка открывается, в архиве есть `wtpoligon.log`.

Окно не должно подвисать при смене машины и шагов. Если подвисает — напишите, где.
